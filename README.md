# 2D Platformer Game

A classic side-scrolling platformer built with Unity.  
The player can run, jump, collect tokens, and complete levels while avoiding enemies and hazards.  
This project is based on Unity’s Platformer Template and can be used as a starting point for your own platformer games.

## Features
- 🎮 Smooth player movement (run, jump, gravity, collisions)  
- 🪙 Token collection system with counter  
- 👾 Enemies with patrol paths  
- 🏆 Victory and death zones for level progression  
- 🎨 Pixel-art style with parallax backgrounds  

## How to Play
- **Arrow keys / WASD** → Move  
- **Spacebar** → Jump  
- Collect all tokens and reach the goal!  

## Getting Started
1. Clone this repository  
2. Open the project in **Unity (2021.3 or later recommended)**  
3. Press **Play** in the editor to try the game
